💡 How the Calculation Works
1. Enter MTD Sales (total sales this month) and each item's MTD Consumption (units used this month).
2. Set On Hand availability for each item.
3. Select Forecast Days (1–10) to project demand.
4. The system calculates C/1000 (consumption per 1000 sales) and To Order = C/1000 × (Forecast Sales / 1000) – On Hand.
5. Goal: Reduce waste by ordering just above the average consumption — not more than the trend.
